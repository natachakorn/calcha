# นับแคล NubCal

ถ่ายรูปหรือเลือกรูปอาหาร แล้ว AI จะบอกแคลอรี่ โปรตีน คาร์บ และไขมัน พร้อมสรุปว่าวันนี้กินไปแล้วกี่ % ของที่ร่างกายต้องการ

## AI ที่ใช้
**Google Gemini API** (มี free tier) เรียกตรงจากเครื่องผู้ใช้ด้วย API Key ของผู้ใช้เอง
- โมเดลเริ่มต้นคือ `gemini-flash-latest` (alias ของรุ่น Flash ล่าสุด) ถ้าคนใช้เยอะหรือใช้ไม่ได้ แอปจะลอง `gemini-3.8-flash` → `gemini-flash-lite-latest` → `gemini-3.5-flash-lite` ให้อัตโนมัติ
- ขอคีย์ฟรีได้ที่ https://aistudio.google.com/apikey
- หมายเหตุ: ข้อมูลที่ส่งผ่าน free tier ของ Google อาจถูกนำไปใช้ปรับปรุงบริการของ Google

### ไม่มีคีย์ก็ใช้ได้
- มีรายการอาหารไทยในแอป 180+ เมนู (`foods.js`) ให้ค้นหาแล้วกดเลือก ไม่ต้องใช้ AI หรืออินเทอร์เน็ต
- ใส่คีย์ได้ง่าย 2 ขั้น: กดเปิดหน้า Google → กลับมากด "วางคีย์" แอปตรวจสอบให้อัตโนมัติ

### AI ส่วนกลาง (ผู้ใช้ไม่ต้องมีคีย์)
โฟลเดอร์ `worker/` เป็น Cloudflare Worker (ฟรี) ที่เก็บคีย์ Gemini ของเจ้าของแอปไว้ฝั่งเซิร์ฟเวอร์
1. แก้ `ALLOWED_ORIGINS` ใน `worker/wrangler.toml` เป็น URL ของ GitHub Pages
2. `cd worker` → `npx wrangler login` → `npx wrangler secret put GEMINI_API_KEY` → `npx wrangler deploy`
3. นำ URL ที่ได้ (`https://calcha-ai.<ชื่อ>.workers.dev`) ไปใส่ `proxyUrl` ใน `config.js`

ทุกคนจะใช้โควต้าฟรีของคีย์เดียวกัน (จำกัด 10 ครั้ง/นาที/เครื่อง) ถ้าโควต้าเต็ม แอปจะแนะนำให้ผู้ใช้ใส่คีย์ของตัวเอง

## การคำนวณความต้องการต่อวัน
- BMR: สูตร Mifflin-St Jeor × ระดับกิจกรรม = TDEE
- เป้าหมาย: ลดน้ำหนัก −500 kcal · คงที่ ±0 · เพิ่ม +300 kcal (ขั้นต่ำ 1,200 สำหรับหญิง / 1,500 สำหรับชาย)
- โปรตีน: 1.6 g/kg (ลด) · 1.2 g/kg (คงที่) · 1.8 g/kg (เพิ่ม)
- กำหนดเป้าหมายเองได้ในหน้า "ข้อมูลฉัน"

## ตรวจรูปซ้ำ
ทุกรูปจะถูกเก็บลายนิ้วมือภาพ (SHA-256 + ภาพย่อขาวดำขนาด 16×16) ถ้าส่งรูปเดิมซ้ำ แม้จะถูกบีบอัดหรือย่อขนาดมาแล้ว แอปจะถามว่า
มื้อเดิม (ไม่นับซ้ำ) / มื้อใหม่ (นับเพิ่ม โดยไม่ต้องเรียก AI อีก) / อาหารอื่น (ให้ AI วิเคราะห์ใหม่)

## ข้อมูลเก็บที่ไหน
เก็บในเครื่องเท่านั้น (localStorage + IndexedDB) ไม่มีเซิร์ฟเวอร์ของเราเอง สำรองหรือย้ายเครื่องได้ด้วยปุ่ม ส่งออก / นำเข้า

## รันบนเครื่อง
```bash
node serve.js
```
เปิด http://localhost:5173 (ใช้มือถือที่ต่อ Wi-Fi เดียวกันเปิดผ่าน IP ที่แสดงได้ แต่กล้องกับการติดตั้งแอปต้องใช้ HTTPS)

## ติดตั้งบนมือถือ (PWA)
อัปโหลดทั้งโฟลเดอร์ขึ้นโฮสต์ที่เป็น HTTPS ได้ฟรี เช่น GitHub Pages, Netlify หรือ Cloudflare Pages แล้วเปิดลิงก์บนมือถือ
- Android (Chrome): เมนู ⋮ → "ติดตั้งแอป" / "เพิ่มลงในหน้าจอหลัก"
- iPhone (Safari): ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"

## ทำเป็นไฟล์ Android (APK / Play Store)
นำ URL ที่โฮสต์แล้วไปใส่ที่ https://www.pwabuilder.com แล้วเลือก Android จะได้แพ็กเกจ TWA สำหรับอัปโหลดขึ้น Play Store หรือใช้ Capacitor ห่อโค้ดชุดนี้ก็ได้
